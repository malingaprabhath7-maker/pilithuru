# Pilithuru — live demo

**Open it:** https://malingaprabhath7-maker.github.io/pilithuru/

Pilithuru (පිළිතුරු) is a chat assistant for small business websites. It answers customers' questions in Sinhala, Singlish and English, and hands anything it can't answer over to the owner's WhatsApp. This repository holds only the built website; the source code is private.
